# Тихая комната

Веб-приложение, которое записывает речь и превращает её в текст, выжимку, конспект и чат с ИИ. Подходит для лекций, рабочих встреч, разговоров и голосовых заметок. Работает в браузере на телефоне и компьютере, ставится на главный экран и открывается без интернета.

## Что умеет

- Запись с микрофона с шумоподавлением. Экран не гаснет, пока идёт запись.
- 4 сценария: лекция, встреча, разговор, заметка. От сценария зависит, что ИИ сделает из текста.
- Распознавание русского и английского через Whisper large-v3 turbo в Cloudflare Workers AI.
- Детектор речи режет звук по паузам на куски до 30 секунд. Тишина не отправляется, поэтому Whisper не выдумывает фразы вроде «Продолжение следует».
- Голоса из зала и помехи прячутся в серые блоки, их можно раскрыть.
- Выжимка из 3–5 пунктов со ссылками на минуту записи.
- Конспект лекции с терминами, итоги встречи с решениями и задачами, чистый текст заметки.
- Чат по записи и кнопка «Объясни проще» для выделенного текста.
- Загрузка готового аудио или видео: MP3, M4A, WAV, OGG, WEBM, MP4.
- Поиск по всем записям.
- Экспорт записи в Markdown и PDF.
- Резервные копии `.zip` с аудио или без. Загрузка копии дополняет данные и пропускает повторы.
- Работа без интернета: записи, тексты и поиск доступны офлайн. Записи без сети встают в очередь и распознаются, когда сеть появится.

## Выкладка на Cloudflare Pages

1. В панели Cloudflare откройте **Workers & Pages → Create → Pages → Connect to Git** и выберите этот репозиторий.
2. Настройки сборки:
   - Framework preset: **None**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Production branch: ветка, в которой лежит код (после слияния pull request это `main`).
3. Нажмите **Save and Deploy**.
4. Проверьте привязку Workers AI. Файл `wrangler.toml` уже объявляет её под именем `AI`. Если в **Settings → Bindings** привязки нет, добавьте **Workers AI** с именем `AI` и пересоберите проект.
5. По желанию задайте переменные в **Settings → Variables and Secrets**:
   - `ACCESS_CODE` — код доступа. Без него любой, кто знает адрес сайта, может тратить ваш лимит Workers AI. Тот же код вводится в приложении: **Настройки → Сервер распознавания**.
   - `EXTRA_LLM_HOSTS` — дополнительные адреса API через запятую, если нужен сервис не из списка ниже.

Node.js для сборки задаётся файлом `.node-version` (версия 22).

## Ключ DeepSeek или другого ИИ

Ключ вводится в приложении: **Настройки → ИИ для выжимок и чата**. Ключ хранится только на устройстве и не попадает в резервные копии.

Запросы к ИИ идут через функцию `/api/llm` на вашем сайте, потому что браузер не может обратиться к большинству сервисов напрямую. Функция пересылает запрос и ничего не сохраняет. Разрешённые адреса: DeepSeek, OpenAI, OpenRouter, Groq, Mistral, Together, xAI, Fireworks, Perplexity, Google Gemini (режим совместимости с OpenAI), Anthropic (режим совместимости с OpenAI).

## Стоимость

- Workers AI даёт бесплатный дневной лимит, сверх него оплата по тарифу Cloudflare.
- Выжимка полуторачасовой лекции в DeepSeek стоит порядка 1–2 центов.
- Звук уходит на распознавание без сжатия: около 115 МБ трафика на час речи. Для длинных лекций лучше Wi‑Fi.

## Разработка

```bash
npm install
npm run dev        # интерфейс без серверных функций
npm test           # 33 теста: слияние копий, нарезка звука, разбор ответов ИИ
npm run build      # проверка типов и сборка в dist/
```

Полный запуск с распознаванием требует входа в Cloudflare, потому что Workers AI работает только в облаке:

```bash
npx wrangler login
npm run build && npx wrangler pages dev dist
```

## Устройство

| Папка | Что внутри |
|---|---|
| `src/audio` | запись с микрофона, детектор речи, перевод в WAV 16 кГц, разбор файлов |
| `src/stt` | очередь распознавания, повторы при ошибках, фильтр выдуманных фраз |
| `src/ai` | запросы к ИИ, промпты по сценариям, выжимка, чат |
| `src/backup` | резервные копии, слияние без повторов, проверка файлов копии |
| `src/screens` | экраны: главный, запись, запись лекции, все записи, настройки, загрузка копии, печать |
| `functions/api` | функции Cloudflare Pages: `transcribe` (Whisper) и `llm` (пересылка к ИИ) |
| `server` | общий код функций: проверка кода доступа и источника запроса |

Данные хранятся в IndexedDB браузера. Приложение просит браузер не удалять их (`navigator.storage.persist`), но резервные копии всё равно нужны.

### Как работает слияние копий

- У каждой записи, фрагмента текста и сообщения чата есть постоянный UUID.
- Запись с тем же UUID не дублируется. Из двух версий берётся более новая, чаты и задачи объединяются по сообщениям и задачам.
- Одинаковое аудио под разными UUID узнаётся по SHA-256 и пропускается.
- Удалённые записи запоминаются, и старая копия их не возвращает.
- Режим «Заменить всё» сначала скачивает копию текущих данных с аудио.

## Ограничения

- iPhone: Safari останавливает микрофон, когда экран заблокирован или приложение свёрнуто.
- Android в браузере: запись в фоне работает не всегда. Надёжная фоновая запись появится в APK.
- Очень длинные загруженные файлы (больше 2 часов) могут не поместиться в память телефона при разборе.
- Деление текста по говорящим пока не сделано.
